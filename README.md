# Задание 1

## Задача 1

### Текст задачи

Создать сущность «Точка», расположенную на двумерной плоскости, которая описывается двумя координатами:

- Координата X — число.
- Координата Y — число.

Точка должна возвращать текстовое представление вида `{X;Y}`.

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

### Алгоритм решения

1. Создать класс `Point`.
2. Объявить два свойства класса `x` и `y` типа `double`.
3. Создать конструктор, принимающий два параметра — координаты X и Y.
4. Использовать `this.x = x` и `this.y = y` для присвоения значений свойствам объекта.
5. Переопределить метод `toString()`, который возвращает координаты точки в формате `{X;Y}`.
6. В классе `Main` создать три объекта класса `Point` с разными координатами.
7. Вывести созданные точки на экран.

### Результат выполнения

Созданы три точки:

- `{3.0;5.0}`
- `{7.0;2.0}`
- `{10.0;8.0}`

Координаты каждой точки выводятся в консоль в заданном формате.

## Задача 3

### Текст задачи

Создать сущность «Имя», которая описывается тремя параметрами:

- Фамилия.
- Личное имя.
- Отчество.

Имя может быть приведено к строковому виду, включающему традиционное представление всех трёх параметров: Фамилия Имя Отчество.

Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан. В этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

- Клеопатра.
- Пушкин Александр Сергеевич.
- Маяковский Владимир.

### Алгоритм решения

1. Создать класс `Name`.
2. Объявить три свойства типа `String`: `surname`, `firstName`, `patronymic`.
3. Создать конструктор, принимающий три параметра.
4. Для отсутствующих частей имени использовать значение `null`.
5. Переопределить метод `toString()`.
6. В методе `toString()` последовательно проверить каждую часть имени на отсутствие значения.
7. Добавлять в итоговую строку только заданные части имени, разделяя их пробелами.
8. В классе `Main` создать три объекта `Name` с указанными в задании именами.
9. Вывести созданные имена на экран.

### Результат выполнения

Созданы и выведены три имени:

- Клеопатра.
- Пушкин Александр Сергеевич.
- Маяковский Владимир.

Незаданные части имени не отображаются.

# Задание 2

## Задача 1

### Текст задачи

Создать сущность «Линия», расположенную на двумерной плоскости, которая описывается:

- Координата начала: Точка.
- Координата конца: Точка.

Линия должна возвращать текстовое представление вида `Линия от {X1;Y1} до {X2;Y2}`.

Для указания координат необходимо использовать сущность «Точка», разработанную в задании 1.1.

Необходимо создать три линии:

1. Линия 1 с началом в точке `{1;3}` и концом в точке `{23;8}`.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается там же, где начинается линия 1, и заканчивается там же, где заканчивается линия 2.

После создания всех трёх объектов необходимо изменить координаты первой и второй линий таким образом, чтобы положение третьей линии соответствовало требованиям.

Затем изменить координаты первой линии так, чтобы при этом не изменились координаты третьей линии.

### Алгоритм решения

1. Создать класс `Line`.
2. Добавить два свойства типа `Point`: `start` и `end`.
3. Создать конструктор, принимающий начальную и конечную точки.
4. Добавить методы получения и изменения начальной и конечной точек.
5. Переопределить метод `toString()`, который возвращает текстовое представление линии.
6. В классе `Main` создать две точки для первой линии и две точки для второй линии.
7. Создать третью линию, используя начальную точку первой линии и конечную точку второй линии.
8. Изменить координаты существующих точек первой и второй линий. Благодаря использованию общих ссылок изменения будут видны и в третьей линии.
9. Заменить начальную точку первой линии новым объектом `Point`.
10. Вывести линии на экран и проверить, что третья линия сохранила ссылку на прежнюю начальную точку.

### Результат выполнения

Созданы три линии с заданными координатами.

Продемонстрировано изменение координат общих точек и влияние этих изменений на третью линию.

После замены начальной точки первой линии третья линия продолжает использовать прежнюю точку.

# Задание 3

## Задача 3

### Текст задачи

Создать сущность «Город», которая будет представлять собой точку на карте со следующими характеристиками:

- Название города.
- Набор путей к следующим городам, где путь представляет собой сочетание города и стоимости поездки в него.

Город должен возвращать текстовое представление в виде названия города и списка связанных с ним городов в формате «название:стоимость».

Используя разработанную сущность, необходимо реализовать схему, представленную на рисунке 2 лабораторной работы.

### Алгоритм решения

1. Создать класс `City`.
2. Добавить свойство `name` для хранения названия города.
3. Добавить список `routes`, в котором хранятся связанные города и стоимости поездок.
4. Создать вспомогательный класс `Route`, содержащий объект `City` и целочисленную стоимость поездки `price`.
5. Создать конструктор города, принимающий его название.
6. Создать метод `addRoute()`, который добавляет новый маршрут в список.
7. Переопределить метод `toString()`, который формирует строку с названием города и списком связанных городов с указанием стоимости поездки.
8. В классе `Main` создать города A, B, C, D, E и F.
9. Добавить маршруты между городами в соответствии со схемой из лабораторной работы.
10. Вывести информацию о каждом городе на экран.

### Результат выполнения

Созданы шесть городов и добавлены маршруты между ними с соответствующими стоимостями поездок.

При выводе каждого города отображаются его название и список связанных городов с ценами маршрутов.

Новые требования включают:

- Город можно создать, указав только название.
- Город можно создать, указав название и набор связанных с ним городов и стоимостей путей к ним.

# Задание 5

## Задача 5

### Текст задачи

Создать сущность «Дробь» со следующими особенностями:

- Имеет числитель: целое число.
- Имеет знаменатель: целое число.
- Дробь может быть создана с указанием числителя и знаменателя.
- Может вернуть строковое представление вида `числитель/знаменатель`.
- Может выполнять операции сложения, вычитания, умножения и деления с другой дробью или целым числом.
- Результатом операции должна быть новая дробь, таким образом, обе исходные дроби не изменяются.

Необходимо выполнить следующие задачи:

1. Создать несколько экземпляров дробей.
2. Написать по одному примеру использования каждого метода.
3. Вывести на экран примеры и результаты их выполнения в формате `1/3 * 2/3 = 2/9`.
4. Посчитать выражение `f1.sum(f2).div(f3).minus(5)`.

### Алгоритм решения

1. Создать класс `Fraction`.
2. Добавить два свойства типа `int`: `numerator` — числитель и `denominator` — знаменатель.
3. Создать конструктор, принимающий числитель и знаменатель.
4. В конструкторе проверить, что знаменатель не равен нулю. Если он равен нулю, выбросить исключение.
5. Переопределить метод `toString()`, который возвращает дробь в формате `числитель/знаменатель`.
6. Создать метод `sum()` для сложения дробей. Для сложения использовать общий знаменатель.
7. Создать метод `minus()` для вычитания дробей.
8. Создать метод `multiply()` для умножения дробей.
9. Создать метод `div()` для деления дробей. Перед делением проверить, что числитель дроби-делителя не равен нулю.
10. Для каждой операции реализовать перегруженный метод, принимающий целое число.
11. Каждая операция должна создавать и возвращать новый объект `Fraction`, не изменяя исходные дроби.
12. В классе `Main` создать несколько объектов `Fraction`.
13. Продемонстрировать сложение, вычитание, умножение и деление дробей и целых чисел.
14. Вычислить выражение `f1.sum(f2).div(f3).minus(5)` и вывести результат.
