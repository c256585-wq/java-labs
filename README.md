# Задание 1

## Задача 1

### Текст задачи

Создать сущность «Точка», расположенную на двумерной плоскости, которая описывается:

- Координата X: число.
- Координата Y: число.

Точка должна возвращать текстовое представление вида `{X;Y}`.

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

### Алгоритм решения

1. Создать класс `Point`.
2. Объявить два свойства класса `x` и `y` типа `double`.
3. Создать конструктор, принимающий координаты X и Y.
4. С помощью `this.x = x` и `this.y = y` присвоить переданные значения свойствам объекта.
5. Переопределить метод `toString()`, чтобы он возвращал координаты точки в формате `{X;Y}`.
6. В классе `Main` создать три объекта класса `Point` с разными координатами.
7. Вывести созданные точки на экран.
